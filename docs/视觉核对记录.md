## 三、核对中发现并修掉的「截图侧」问题

这两条不是产品缺陷，但会让交付图看起来像 bug：

1. **toast 盖在内容上**：截图时刚触发的「已保存为聚餐方案」绿色提示压住了票根底部。已在截图脚本里加 `waitToastsClear()`，等提示自然消失再拍。
2. **长图拼接出「重复顶栏」**：Chromium `fullPage` 截图会把 `position: sticky` 的元素画在分片边界上，票根页看起来像有两张票根。已在拍摄瞬间把 `.topbar / .edit-right / .menu-group__title` 临时改为 `static`，拍完立即恢复。
