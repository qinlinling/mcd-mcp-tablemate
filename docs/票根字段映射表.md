# 同桌食光票根字段映射表

对应规划：D01、5.6 节、12.4 验收标准。
原则：**票根只是最终确认方案的自然输出**，每个字段都要能指回「哪个数据来自哪里」，
没有来源的字段一律不出现（尤其金额、订单号、门店详址）。

## 一、字段映射

| 票根字段 | 模型键 | 事实来源 | 处理规则 | 默认展示 |
|---|---|---|---|---|
| 票根编号 | `ticketId` | `t_{partyId}_{planId}` | 仅用于本地预览与下载文件名，不含个人信息 | 否（只用于导出文件命名） |
| 关联聚餐 | `partyId` | `Party.id` | — | 否 |
| 状态徽章 | `status` / `statusLabel` | `Party.status` | `completed → 已完成`；其余一律 `planning → 计划中` | ✅ |
| 聚餐事由 | `title` | `Party.title`（用户创建时填写） | 原样，最长 30 字 | ✅ |
| 日期 | `date` | `Party.createdAt`；若 `confirmedAt` 存在则用它 | `YYYY-MM-DD` | ✅ |
| 同桌成员 | `members[]` | `Party.members[].nickname` | 用户在票根页可逐个改写；超过 6 人折叠为「等 N 人」 | ✅ |
| 代表餐品 | `items[].name/quantity/assignee` | `Party.confirmedPlan.items[]` | 每件餐品必须有归属人；同一归属人只保留 1 件（按数量降序），总数 ≤ 3 | ✅ |
| 被满足的小心愿 | `wishes[]` | `confirmedPlan.wishResults[*].must` 中 `status=="satisfied"` 的项 | 每人最多 1 条、最多 4 条；只收「必须要」被满足的，不把「最好有」包装成心愿 | ✅ |
| 主题短句 | `themeLine` | 用户输入；为空时用模板 `{人数} 个人，一顿{事由}` | 不含比较级/绝对化用语 | ✅ |
| 数据时点 | `dataTime` | `Party.dataTime`（MCP 返回的 datetime） | 回放模式下保留原始时点 | ✅（小字） |
| 数据来源 | `dataSource` | `live / replay` | `replay` 时票根标注「离线回放」 | ✅（小字） |
| 生成时间 | `generatedAt` | 服务器本地时间 | — | 否 |
| 字段可见性 | `fieldsVisible` | 用户勾选 | 未勾选的字段**不渲染**（不是 `display:none`） | — |
| 脱敏声明 | `hiddenFields` | 固定常量 | 见下 | ✅（小字） |

## 二、默认隐藏（硬性）

| 隐藏项 | 原因 |
|---|---|
| 订单号 | 规划 12.4；且 MVP 不下单，本就没有 |
| 门店详址 | 暴露常去门店等于暴露生活轨迹 |
| 个人预算 | 属于个人财务信息，发起人无权公开 |
| 个人分摊 | 同上，且容易引发「谁多付了」的比较 |
| 实际支付金额 | 计划中的方案不存在实际支付；展示金额会让票根看起来像消费凭证 |

> 校验方式：`tests/e2e_smoke.py` 最后一步对票根 JSON 做关键词扫描，
> 一旦出现 `totalCents / shareCents / storeName / address / orderId` 即判失败。
> 前端 `tests/ui_smoke.mjs` 另有一条断言：票根 DOM 文本中出现 `¥数字` 即失败。

## 三、状态语义（防止「计划」被当成「已消费」）

| Party.status | 票根 status | 徽章文案 | 允许的操作 |
|---|---|---|---|
| draft / planned | planning | 计划中 | 还需先确认方案 |
| confirmed（用户点了「确认这套方案」） | planning | 计划中 | 可生成票根、可标记完成 |
| completed（用户在票根页勾选「这次已经吃完了」并二次确认） | completed | 已完成 | 可取消标记 |

`completed` 只代表「用户自己确认这顿吃过了」，**不代表**有订单、有支付、有消费凭证。
规划把「关联真实订单」列在 P1，本项目未实现，因此票根上没有任何订单相关信息。

## 四、视觉与导出

| 项 | 实现 |
|---|---|
| 版式 | 420px 宽纸质票根，左右撕线（半圆锯齿）+ 中间撕裂线 |
| 配色 | 奶油白 `#FFF8EC` / 暖红 `#DA291C` / 麦黄 `#FFC72C` |
| 质感 | CSS 渐变叠出纸纹；手写短句用 `Kaiti SC / KaiTi` 回退 |
| 强调 | 不使用红绿单独表意；状态用「文字 + 图标」双通道 |
| 导出 | `TicketRenderer.exportPNG` 用 canvas 手绘（非截图 DOM），输出 1080 宽、2x 像素比，中文按 `measureText` 逐字折行 |
| 字体 | 只依赖系统字体，无网络字体，断网也能正确导出 |
